# 功能范围与验证边界

## 与上游的关系

本分支延续 Flow2API 的协议适配和管理能力，新增 `flow.google.com` 会话、素材账号亲和、编辑输入、中文错误和原始上游错误码、请求参考素材预览以及 Cookie 同步日志。保留 MIT 声明，不把原项目贡献归为 Qzent 原创。

## 新版网页模式

| 功能 | 当前范围 | 验证依据 |
|---|---|---|
| 文生图 | 原始分辨率 | 既有生产生成成功；自动化路径测试 |
| 参考图编辑 | 原始分辨率 | 既有生产生成成功；自动化路径测试 |
| 文生视频 | 受模型和账号权限限制 | 既有生产生成成功 |
| 图生视频、首尾帧、参考图视频 | 支持已适配输入组合 | 既有生产代表性请求成功，未遍历所有模型组合 |
| 视频上传与编辑 | Base64 MP4 上传、生成或上传后返回的 media_id | 既有生产成功，包含下载及视频解码检查 |
| OpenAI / Gemini 兼容接口 | 支持已有生成路径，含流式输出 | 既有生产代表性请求成功 |
| 图片 2K / 4K 放大 | 新版路径尚未适配 | 返回 `flow_operation_unsupported`，不可因模型目录有名称就视为支持 |
| 视频续写、视频放大 | 不纳入新版已支持范围 | 不支持的组合会拒绝；未完成新版真实生成验证 |
| 验证码服务 | YesCaptcha / CapMonster / EzCaptcha / CapSolver | 新版生成路径的配置白名单；并非逐个服务都做过本次线上验证 |

2026-09-12 既有回归记录包含 10 次直接 Flow2API 真实生成，图片、视频和编辑都有成功结果。本次开源准备主要验证空安装、鉴权和打包，没有再次消耗 Google 积分复跑全部生成。既有记录不能替代新账号、新网络和新验证码配置下的首次验收。

## 限制

- Google 会调整网页协议；会话验证通过不保证后续每次生成成功。
- 模型目录保留历史别名与兼容变体，其存在不代表新版支持所有参数组合。
- 编辑素材归属原 Google 账号，缺少所属账号时必须报错，不能换账号继续。
- 参考素材预览仅适用于已记录输入信息的新日志；旧日志不能凭空恢复素材，缓存删除后预览也可能不可用。
- 已有旧协议账号与部分编辑配置仍保留兼容逻辑；新增账号默认使用新版 Cookie。不能宣称后端已经完全删除旧协议。
- 既有验证码指纹测试已修复初始化问题；它验证模拟服务返回的 User-Agent 传递，不等同于所有验证码服务都经过线上实测。
- 源视频格式、所有时长、画幅、分辨率及风控失败类型未做穷举线上验证。
- 密钥更新后调用方需要同步更新；API Key、插件连接 Token 和 Google Cookies 是三类独立凭据。
